# Что показать на защите

1. Запусти Docker и выполни `docker compose up --build -d --wait`.
2. В браузере открой http://127.0.0.1:8080. Создай заметку «План на неделю», выбери «Учёба», затем поменяй её текст.
3. Покажи три контейнера командой `docker compose ps` и запусти `python3 scripts/check.py`.
4. Пересоздай notes командой `docker compose up -d --force-recreate --wait notes`. Обнови страницу и покажи, что заметка сохранилась.

На защите достаточно объяснить три вещи:

- Браузер обращается к Nginx. Тот передаёт запросы к notes или labels по имени в сети Docker.
- Заметка остаётся после удаления контейнера, потому что файл SQLite лежит в отдельном томе.
- В Swarm у notes одна реплика на узле с томом. У web и labels нет локального состояния, поэтому для них можно запустить несколько реплик.

Compose и API проверены локально. Для Swarm проверена конфигурация `docker stack config -c stack.yaml`, а запуск временного кластера описан в GitHub Actions. Запуск workflow появится после размещения проекта в репозитории.
